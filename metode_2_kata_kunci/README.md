# Metode 2 – Leksikon / Kata Kunci (baseline)

Menghitung kemunculan kata dari kamus per kategori (kata utuh, frasa terpanjang dulu). Skor tertinggi menang; tanpa kecocokan → Manajemen Lalu Lintas. Sentimen = jumlah kata positif vs negatif.

- `classifier.py` – kamus kategori + penentuan kategori.
- `sentiment.py` – kamus sentimen + penentuan sentimen.
- Tidak butuh data latih dan tidak punya kelas *Tidak Relevan*.
